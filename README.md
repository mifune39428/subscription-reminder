# サブスク更新前リマインダー

Gmailに届いている請求メールから、**契約中のサブスクを自動で洗い出して、
更新日の数日前にだけ**メールで知らせるmacOS用のツールです。

「気づいたら更新されていた」をなくすためのものです。
サブスクを自分で一覧に書き出す必要はありません。

## 届くもの

- 何日後に、どのサブスクが、いくらで更新されるか
- 月あたりの合計金額（年額のものは月割りして足します）
- しばらく使っていないサブスク（解約候補）
- 解約ページへのリンク（分かるサービスだけ）

更新が近いものが無い日は、何も届きません。同じ更新について二度は送りません。

## 必要なもの

- macOS（毎日の自動起動に launchd を使っています。Windowsでは動きません）
- Python 3（ターミナルで `python3` と打って動けばOK）
- 請求メールが届いているGmailと、その[アプリパスワード](https://myaccount.google.com/apppasswords)

## 使い方

1. このリポジトリをダウンロードして、好きな場所に置く
   （あとで動かすと自動起動が外れるので、置き場所は先に決めてください）
2. `setup_wizard.command` をダブルクリック
   （「開発元を確認できません」と出たら、右クリック →「開く」）
3. 画面の質問に答える（Gmailのアドレスとアプリパスワード、何日前に知らせるか、など）
4. 最初の洗い出しで、見つかったサブスクの一覧が出ます。
   メールが多いと、読み終わるまで10分ほどかかります
5. あとは毎日決まった時刻に確認して、更新が近いものがあればメールが届きます

いまの一覧を見たいときは `subscription_list.command` をダブルクリックしてください（メールは送りません）。

## どうやって見つけているか

- Gmailの「購入」に分類されたメールと、よくあるサービスの送信元から請求メールを探します
- 同じ送信元・同じ件名・ほぼ同じ金額の請求が、毎月・毎年などの間隔で届いていればサブスクとみなします
- 1回しか請求が見つからない年額契約などは「サブスクかも（要確認）」に出します

メールは**読むだけ**です。既読にしたり、消したり、移動したりはしません。

## 「使っていない」の判定

Chromeの閲覧履歴と、Macアプリの最終起動日を見て、60日以上使っていないものを解約候補にします。
読むのはこのMacの中のデータだけで、外には送りません。どちらもウィザードで切れます。

アプリの起動日を正確に読むには、ターミナルに**フルディスクアクセス**が要ります
（システム設定 → プライバシーとセキュリティ）。許可しなくても動きますが、推定の精度が落ちます。

## 判定を直す

間違って拾ったもの、名前が分かりにくいもの、**請求メールが来ない契約**（Amazonプライムなど）は、
`overrides_example.json` を `overrides.json` という名前でコピーして書き足してください。

- `"ignore": true` … 一覧から外す
- `"name"` … 表示名を変える
- `manual` … 請求メールが来ない契約を手で足す

手で足した契約の更新日は、ターミナルからも入れられます。

```bash
python3 watch.py --set-renewal amazon-prime 2026-11-04
```

## 保存される場所

入力した内容は、このフォルダの `config.json` に保存されるだけです。どこにも送信しません。
`config.json` と、取得したメールの控え（`mail_cache.json`）は `.gitignore` に入れてあります。

## やめるとき

```bash
launchctl unload ~/Library/LaunchAgents/com.subscription.reminder.plist
```

フォルダごと消せば、Macには何も残りません。

## 分かっている限界

- **メールが来ない課金は見つけられません。** カード明細にしか出ないものは `overrides.json` に手で足してください
- **Appleの領収書は中身まで分けられません。** 曲やアプリの購入とサブスクが混ざります。
  Appleのサブスクは https://apps.apple.com/account/subscriptions で直接見るのが確実です
- 日本語の請求メールを前提に調整しています
- 作者のMac以外での動作は、まだ十分に検証できていません。うまくいかなかったら Issue で教えてください
