================================================================
💳 サブスク更新前リマインダー
   Gmailの請求メールから契約中のサブスクを見つけて、
   更新日の数日前にだけ、メールで知らせます。
================================================================

■ これは何か

「気づいたら更新されていた」をなくす道具です。
サブスクの一覧を自分で作る必要はありません。Gmailに届いている請求メールから、
あなたのMacが勝手に探して、更新が近いものだけ教えてくれます。

届くメールの中身:
  ・何日後に、どのサブスクが、いくらで更新されるか
  ・月あたりの合計金額
  ・しばらく使っていないサブスク（解約候補）
  ・解約ページへのリンク（分かるサービスだけ）

更新が近いものが無い日は、何も届きません。


■ 必要なもの

・Mac（macOS）。Windows では動きません
・Python 3（ターミナルで python3 と打って動けばOK）
・請求メールが届いている Gmail と「アプリパスワード」
  → https://myaccount.google.com/apppasswords


■ 使い方（15分）

1. このフォルダを好きな場所に置く
   （あとで動かすと自動起動が外れるので、置き場所は先に決めてください）

2. setup_wizard.command をダブルクリック
   「開発元を確認できません」と出たら、右クリック →「開く」を選びます。

3. 画面の質問に答える
   ・パスワードは画面に表示されません
   ・入力内容は、このフォルダの config.json に保存されるだけで、外には送られません

4. 最初の洗い出し
   直近400日ぶんの請求メールを読みます。メールが多いと10分ほどかかります。
   終わると、見つかったサブスクの一覧が出ます。

5. あとは毎日決まった時刻に確認して、更新が近いものがあればメールが届きます


■ いまの一覧を見たいとき

subscription_list.command をダブルクリックしてください。メールは送りません。
届くメールの見本が report_preview.html に書き出されます。


■ 間違って拾った／足りないとき

overrides_example.json を overrides.json という名前でコピーして書き足します。
  ・"ignore": true … 一覧から外す
  ・"name" … 表示名を変える
  ・manual … 請求メールが来ない契約（Amazonプライムなど）を手で足す


■ 自動起動をやめたいとき

ターミナルで:
  launchctl unload ~/Library/LaunchAgents/com.subscription.reminder.plist

フォルダごと消せば、Mac には何も残りません。


■ うまくいかないとき

・Gmailの読み取りでエラーになる
  → Gmail のアプリパスワードを確認してください。ログインパスワードでは読めません。
  → Gmail の設定で IMAP が有効になっているか確認してください。

・サブスクが1件も出ない
  → 請求メールを消していると見つかりません。
  → 最初の洗い出しが途中で止まっていないか、subscription_list.command を
     もう一度実行して「未取得 0件」になるか見てください。

・「knowledgeC.db を読めません」と出る
  → エラーではありません。アプリの起動日を推定で済ませている、というお知らせです。
     正確にしたいときは、ターミナルにフルディスクアクセスを許可してください。

・エラーの記録は launchd_stderr.log に残ります。
